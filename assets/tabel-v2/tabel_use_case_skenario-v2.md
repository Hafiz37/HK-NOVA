Redirect ke dashboard dengan akses sesuai role | Manager NOC (admin), operator noc (operator), atau mitra (viewer) memiliki akun aktif dan belum terautentikasi | User berhasil login dengan session aktif dan hak akses sesuai role |
| UC-02 | Memantau status dan analitik backup<br>HKN-002, HKN-011 | 1. Buka dashboard untuk melihat ringkasan perangkat pusat dan mitra, status, serta aktivitas backup terbaru<br>2. Buka analitik dan pilih periode<br>3. Tampilkan tren backup, tingkat keberhasilan, dan penggunaan penyimpanan | Manager NOC (admin), operator noc (operator), atau mitra (viewer) sudah login | Ringkasan status dan analitik backup ditampilkan sesuai data serta periode yang dipilih |
| UC-03 | Mengelola perangkat dan kelompok perangkat<br>HKN-003, HKN-005 | 1. Pilih tambah, ubah, atau hapus perangkat pusat maupun mitra lalu simpan perubahan<br>2. Kelola grup dan tempatkan perangkat pada kelompok pusat atau mitra terkait untuk pengaturan jadwal serta tujuan backup<br>3. Pilih perangkat dan jalankan test koneksi SSH; tampilkan hasil berhasil atau gagal | Manager NOC (admin) atau operator noc (operator) sudah login; kredensial SSH tersedia untuk pengujian koneksi | Data perangkat dan kelompok diperbarui sesuai tindakan; hasil pengujian koneksi ditampilkan jika pengujian dijalankan |
| UC-04 | Mengelola kredensial perangkat<br>HKN-004 | 1. Pilih tambah, ubah, atau hapus kredensial SSH perangkat<br>2. Input atau perbarui data kredensial untuk tindakan tambah atau ubah<br>3. Validasi perubahan, enkripsi data sensitif yang disimpan, dan perbarui daftar kredensial | Manager NOC (admin) sudah login | Kredensial diperbarui sesuai tindakan dan data sensitif yang disimpan terenkripsi |
| UC-05 | Mengelola destination storage backup<br>HKN-006 | 1. Pilih tambah, ubah, uji, atau hapus destination Local, Git, SMB, atau Telegram<br>2. Input konfigurasi untuk tambah atau ubah; jalankan pengujian jika memilih uji koneksi<br>3. Validasi dan simpan perubahan atau tampilkan hasil pengujian sesuai tindakan | Manager NOC (admin) sudah login; konfigurasi tujuan tersedia untuk penambahan atau pengujian | Destination diperbarui atau hasil pengujian koneksi ditampilkan sesuai tindakan |
| UC-06 | Menjadwalkan backup otomatis<br>HKN-007 | 1. Pilih perangkat pusat atau mitra, tujuan penyimpanan, dan jadwal backup<br>2. Validasi jadwal lalu simpan dan aktifkan penjadwalan<br>3. Saat jadwal tiba, sistem menjalankan backup melalui SSH menggunakan UC07 sebagai relasi include | Manager NOC (admin) atau operator noc (operator) sudah login saat mengatur jadwal; perangkat, kredensial SSH, dan tujuan penyimpanan terkonfigurasi | Jadwal tersimpan; saat dieksekusi, hasil backup dicatat tanpa perlu pemicu manual atau session pengguna tetap aktif |
| UC-07 | Mengelola backup konfigurasi<br>HKN-008 | 1. Pilih perangkat dan jalankan backup manual, atau terima pemicu dari jadwal UC06<br>2. Sistem mengambil konfigurasi perangkat melalui SSH dan menyimpan hasil ke tujuan yang dikonfigurasi<br>3. Sistem menghitung hash SHA-256, membandingkan dengan versi sebelumnya jika tersedia, serta mencatat versi, timestamp, dan status untuk riwayat HKN-015<br>4. Tampilkan hasil backup; jika gagal, penanganan melalui UC08 tersedia sebagai relasi extend | Manager NOC (admin) atau operator noc (operator) sudah login untuk backup manual, atau jadwal aktif telah tiba; perangkat, kredensial SSH, dan tujuan penyimpanan terkonfigurasi | Hasil dan status backup tercatat; pada keberhasilan, konfigurasi beserta metadata versi tersedia untuk dilihat melalui UC11 |
| UC-08 | Menangani kegagalan backup<br>HKN-012 | 1. Pilih catatan backup yang gagal<br>2. Pilih retry backup atau tandai masalah selesai sesuai hasil penanganan<br>3. Sistem menjalankan ulang backup atau memperbarui status penyelesaian sesuai tindakan | Manager NOC (admin) atau operator noc (operator) sudah login dan terdapat catatan backup gagal; skenario memperluas UC07 pada kondisi backup gagal | Hasil percobaan ulang tercatat atau masalah ditandai selesai; retry tidak selalu menghasilkan backup berhasil |
| UC-09 | Mengelola pengguna dan hak akses<br>HKN-013 | 1. Pilih tambah, ubah, atau hapus akun pengguna<br>2. Atur data akun, status aktif, dan role Admin, Operator, atau Viewer sesuai tindakan<br>3. Validasi aturan akun dan simpan perubahan | Manager NOC (admin) sudah login | Akun, status, dan hak akses pengguna diperbarui sesuai tindakan yang valid |
| UC-10 | Melihat audit log<br>HKN-014 | 1. Buka menu audit log<br>2. Pilih filter aktivitas yang tersedia<br>3. Tampilkan catatan aktivitas pengguna dan perubahan data sesuai filter | Manager NOC (admin) sudah login | Audit log ditampilkan untuk memantau aktivitas pengguna dan perubahan data sistem |
| UC-11 | Melihat riwayat, mengunduh backup, dan membandingkan versi konfigurasi<br>HKN-008, HKN-009, HKN-015 | 1. Buka riwayat pekerjaan atau backup untuk melihat perangkat, waktu, status, dan hasil pelaksanaan<br>2. Pilih backup untuk melihat konfigurasi, timestamp, serta informasi perubahan berdasarkan perbandingan hash SHA-256 yang dicatat sistem<br>3. Unduh file backup jika diperlukan<br>4. Pilih dua versi konfigurasi perangkat yang sama untuk menampilkan unified diff sebagai audit trail perubahan dan bahan troubleshooting | Manager NOC (admin), operator noc (operator), atau mitra (viewer) sudah login; data riwayat tersedia, file tersedia untuk dilihat atau diunduh, dan dua versi perangkat yang sama tersedia untuk perbandingan | Riwayat dan konfigurasi ditampilkan; file diunduh atau unified diff ditampilkan sesuai tindakan tanpa mengubah konfigurasi perangkat |
| UC-12 | Mengelola backup multi-channel Telegram<br>HKN-016 | 1. Atur channel Telegram mitra melalui pengaturan lokasi atau mitra dan channel monitoring pusat melalui pengaturan Telegram yang diizinkan<br>2. Validasi konfigurasi lalu simpan pemetaan channel mitra serta pusat<br>3. Saat backup dijalankan, sistem mengirim file hanya ke channel mitra terkait dan channel pusat sesuai pemetaan | Manager NOC (admin) atau operator noc (operator) sudah login saat konfigurasi; bot memiliki akses ke channel tujuan dan perangkat terhubung dengan mitra yang sesuai | Pemetaan channel tersimpan; pada pengiriman berhasil, backup tersedia di channel mitra terkait dan pusat tanpa dikirim ke channel mitra lain |
| UC-13 | Melihat diagnosis kegagalan backup<br>HKN-012 | 1. Buka menu diagnosis dan pilih periode atau status kegagalan<br>2. Pilih perangkat atau catatan kegagalan<br>3. Tampilkan detail error, riwayat kegagalan, dan informasi diagnosis | Manager NOC (admin), operator noc (operator), atau mitra (viewer) sudah login; catatan kegagalan tersedia untuk melihat detail | Diagnosis kegagalan ditampilkan tanpa menjalankan retry atau mengubah status penyelesaian |
| UC-14 | Mengelola notifikasi backup<br>HKN-010 | 1. Tambah atau ubah saluran notifikasi dan simpan konfigurasi<br>2. Kirim pemberitahuan melalui saluran yang dikonfigurasi | Manager NOC (admin) atau operator noc (operator) sudah login saat konfigurasi; saluran valid dan dapat diakses untuk pengiriman | Konfigurasi notifikasi tersimpan; pemberitahuan status terkirim jika pengiriman berhasil |
