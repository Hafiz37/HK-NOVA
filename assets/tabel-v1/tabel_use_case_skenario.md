| Kode | Nama Use Case | Basic Flow | Pre Condition | Post Condition |
|------|---------------|------------|---------------|----------------|
| HKN-001 | Melakukan autentikasi login | 1. Input username dan password<br>2. Validasi kredensial dan buat session<br>3. Redirect ke dashboard | User belum terautentikasi | User berhasil login dengan session aktif |
| HKN-002 | Menambah data perangkat jaringan | 1. Input data perangkat (hostname, IP, device type, group, engine)<br>2. Validasi dan simpan ke database<br>3. Tampilkan di daftar devices | Admin sudah login | Data perangkat tersimpan dan muncul di daftar |
| HKN-003 | Mengelola kredensial SSH perangkat | 1. Input username, password/SSH key, enable secret<br>2. Enkripsi kredensial dengan Fernet<br>3. Simpan ke database | Admin sudah login | Kredensial SSH tersimpan terenkripsi |
| HKN-004 | Mengelompokkan perangkat per mitra | 1. Input nama group mitra dan deskripsi<br>2. Assign perangkat ke group<br>3. Simpan relasi perangkat dengan group | Admin login dan data perangkat tersedia | Perangkat berhasil dikelompokkan per mitra |
| HKN-005 | Menguji koneksi SSH ke perangkat | 1. Pilih perangkat dan trigger test connection<br>2. Ambil kredensial dan coba koneksi SSH<br>3. Tampilkan status berhasil/gagal dengan error message | Perangkat dan kredensial sudah terkonfigurasi | Status koneksi SSH ditampilkan |
| HKN-006 | Mengelola destination storage backup | 1. Pilih tipe destination (Local, Git, SMB, Telegram)<br>2. Input konfigurasi sesuai tipe<br>3. Validasi koneksi dan simpan | Admin sudah login | Destination storage tersimpan dan siap digunakan |
| HKN-007 | Mengelola konfigurasi bot Telegram | 1. Input bot token dari BotFather<br>2. Validasi token dengan Telegram API<br>3. Enkripsi dan simpan bot token | Admin sudah membuat bot Telegram | Bot Telegram terkonfigurasi dan siap digunakan |
| HKN-008 | Mengatur channel Telegram per mitra | 1. Pilih group mitra<br>2. Input chat ID channel Telegram mitra<br>3. Validasi chat ID dan simpan relasi | Bot Telegram sudah terkonfigurasi | Channel Telegram per mitra terkonfigurasi untuk isolasi data |
| HKN-009 | Mengatur channel monitoring pusat | 1. Input chat ID channel monitoring pusat<br>2. Validasi chat ID dengan bot token<br>3. Aktifkan dual upload (channel mitra + pusat) | Bot Telegram dan channel pusat sudah dibuat | Channel monitoring pusat terkonfigurasi menerima semua backup |
| HKN-010 | Menjadwalkan backup otomatis perangkat | 1. Pilih perangkat/group, destination, dan input jadwal cron<br>2. Validasi cron expression<br>3. Simpan job dan daftarkan ke APScheduler | Admin login dan perangkat dengan destination terkonfigurasi | Job backup terjadwal tersimpan dan akan dieksekusi otomatis |
| HKN-011 | Melakukan backup konfigurasi via SSH | 1. Trigger backup dan koneksi SSH dengan kredensial terenkripsi<br>2. Eksekusi command backup sesuai device type<br>3. Simpan file backup ke storage lokal | Perangkat, kredensial, dan destination terkonfigurasi | File backup tersimpan di storage lokal dengan timestamp |
| HKN-012 | Mendeteksi perubahan konfigurasi | 1. Hitung hash SHA256 file backup baru<br>2. Bandingkan dengan hash backup sebelumnya<br>3. Tandai status "changed" atau "unchanged" | File backup baru sudah tersimpan | Status perubahan konfigurasi terdeteksi dan tersimpan |
| HKN-013 | Menyimpan versi konfigurasi dengan timestamp | 1. Buat record backup baru di database<br>2. Simpan metadata (timestamp, hash, device_id, status, destination)<br>3. Commit transaction | File backup tersimpan dan hash dihitung | Versi konfigurasi tersimpan dengan timestamp untuk history versioning |
| HKN-014 | Mengunggah backup ke channel Telegram sesuai mitra | 1. Baca file backup, compress dengan gzip, dan split jika >50MB<br>2. Upload ke channel Telegram mitra dengan caption metadata<br>3. Upload ke channel monitoring pusat | Backup tersimpan dan channel Telegram terkonfigurasi | File backup terupload ke channel mitra dan pusat dengan isolasi data |
| HKN-015 | Mengirim notifikasi status backup | 1. Cek status backup dan format pesan notifikasi<br>2. Kirim notifikasi ke channel Telegram<br>3. Kirim via Apprise jika terkonfigurasi | Proses backup selesai dengan status success/failed | Notifikasi status backup terkirim |
| HKN-016 | Menampilkan dashboard status backup | 1. Query statistik backup dari database<br>2. Hitung device total, backup success, dan failed<br>3. Render dashboard dengan chart dan tabel | User sudah login | Dashboard menampilkan ringkasan status backup dengan statistik real-time |
| HKN-017 | Melihat history log backup dan audit trail | 1. Pilih filter (tanggal, perangkat, mitra, status)<br>2. Query backup records sesuai filter<br>3. Tampilkan list backup dengan timestamp, hash, status | User login dan data backup tersedia | History log backup ditampilkan dengan detail lengkap |
| HKN-018 | Menampilkan diff perubahan antar versi | 1. Pilih dua versi backup dengan checkbox<br>2. Fetch kedua file dan buat unified diff<br>3. Render diff viewer dengan highlight perubahan | Minimal ada 2 versi backup | Diff viewer menampilkan perubahan line-by-line antar versi |
| HKN-019 | Melakukan restore backup dari Telegram | 1. Cari backup dengan filter<br>2. Fetch file backup dari Telegram atau local storage<br>3. Tampilkan konten atau download file untuk restore manual | Backup file tersimpan di Telegram atau local storage | File backup berhasil diunduh dan siap untuk restore |
| HKN-020 | Menampilkan alert backup gagal dan retry mechanism | 1. Deteksi backup failed dan tampilkan alert dengan error message<br>2. Catat error log dan retry count<br>3. Trigger retry manual atau otomatis | Backup gagal dan error message tersimpan | Alert backup gagal ditampilkan dan retry dapat dilakukan |
