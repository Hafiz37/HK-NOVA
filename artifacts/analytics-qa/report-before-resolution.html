Executive Summary

Rilis perlu ditunda karena integritas periode dan angka laporan belum terjamin. Autentikasi, operasi ekspor, refresh tanpa reload, dan penanganan database kosong bekerja. Prioritas rilis: batas tanggal/kontrak range, konsistensi status backup, daftar perangkat bermasalah, lalu spesifikasi visual dan mobile.

Pengujian 3 November 2026, working tree berbasis commit 7e36b53 (termasuk perubahan pengguna yang belum di-commit). FastAPI asli + middleware autentikasi, SQLite in-memory, Chrome headless, ApexCharts/Bootstrap aset lokal. Waktu API dibekukan 2026-11-03 12:00 UTC untuk hasil deterministik. Lifespan/scheduler sengaja dinonaktifkan; tidak ada koneksi backup ke perangkat riil atau perubahan database produksi.

28 perangkat / 3 tipe / 1 grup. Target 1 Oktober: 28 backup = 16 sukses + 12 gagal (57,14%). Ada backup sebelum dan setelah batas, 21 sukses dalam 7 hari terakhir, serta 6 kegagalan dalam 24 jam terakhir. Fixture tambahan: database kosong, hanya sukses, dan keempat status backup.

Ini pengujian sistem lokal dengan data sintetis, bukan validasi statistik database produksi. Cakupan browser Chrome saja; Firefox/Safari, load test, serta scheduler/engine perangkat di luar pengujian ini. PASS pada transport/filter UI tidak menyatakan akurasi agregasi; akurasi diuji pada baris INT/CHART/EXP-FILTER. Skor keberhasilan skenario bukan persentase kesiapan rilis.

Reproduksi: GET /api/v1/analytics/reliability-score?days=30&start_date=2026-10-01&end_date=2026-10-01. Expected 28 / 57,14%; actual 56 / 66,07%. CSV/XLSX/JSON/PDF mengikuti 56 sementara trend 28. Gunakan parser range bersama dengan batas >= start dan < end+1 hari pada semua query.
